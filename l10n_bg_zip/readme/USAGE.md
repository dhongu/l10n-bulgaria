1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the Bulgarian localities of that code are listed with their province.

   ![Cities list filtered on the postal code 5300: 32 localities of the province Gabrovo (BG)](static/description/en/01_lista_localitati_cap.png)

2. Open a Bulgarian contact and type the postal code in the address: the city and the
   province are filled in.

   ![Contact in Bulgaria: the postal code 6300 fills in the city Haskovo (6300) and the state Haskovo (BG)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the province is filled in;
   choose the city from the list (type the postal code or the name in the city field).

   ![Contact in Bulgaria: the postal code 5300 fills in the state Gabrovo (BG); the city field lists the localities of 5300](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Bulgaria: set city from ZIP*.

   ![Contacts list with Bulgarian contacts selected and the Actions menu open on Bulgaria: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Klient Plovdiv after the action: ZIP 4000, city Plovdiv (4000) and state Plovdiv (BG)](static/description/en/05_contact_dupa_actiune.png)

The localities are named in Latin; with the Bulgarian language installed, users working in
Bulgarian see them in Cyrillic.
